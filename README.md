# About this project

This is a project to control a model railway using a Raspberry Pi Pico 2W.

## Project stages 

### First stage - completed ✅

The first stage of the project is to control servos which change the points on the layout.  The points can be changed by either pressing a button or via a webpage.

### Second stage - in progress

The next stage is to develop a Pico webpage to generate a starting position for the wagons and the train of wagons required after shunting them.  

An initial version of the code has been developed, but needs further work to allow for the sidings having different lengths (and so wagon storage capacity).  The webpage generated by the Pico 2W is also slow to load (but this may be the best that can be achieved).

In the meantime, a spreadsheet has been created in the folder 'Puzzle' to do this.  Every time the spreadsheet is updated (by pressing f9), it will generate a new puzzle.  

### Third stage - in planning

This stage is to allow for the wagons to be uncoupled from the shunter/locomotive by a raising plate (instead of the human hand).  The idea is that the plate is raised using a servo (which is plugged into spare ports on the servo board).

### Further stages

Further stages being considered at February 2026 are:
- the building of custom PCBs for switching the points which would include LEDs to illuminate the position of the points and connecting track.  (Think of a modern signal box schematic).  This will probably require controlling multiple LEDs from just one GPIO pin.
- the detection of shunter/locomotive and wagon positions on the layout using computer vision.  This has the advantage of introducing 'safety-like' features to the layout to prevent (1) locos trying to cross points which are not set correctly and (2) points being changed when there are locos/wagons on the point.  This likely to require a Raspberry Pi and a camera module.  

These stages will require learning about:
- Kicad and designing your own PCBs.
- Computer vision (and using AI for object recognition)

## Micropython code

The Micropython files for the Pico 2W are in the folder Micropython.  It is assumed that you have followed the instructions to install the correct firmware (UF2 file) on the Pico 2W.  These files can be downloaded and copied onto the Pico 2W in Thonny.  

NOTE: The secrets.py needs to be updated with the SSID and password for your own WIFI network.

## Further details

Further details of the project can be found in the presentation called Project details and reflections.odp

Further details of this type of Inglenook layout can be found at:
https://www.wymann.info/ShuntingPuzzles/Inglenook/inglenook-trackplan.html

Whilst this project is based on an N gauge (1:144 scale) model railway, it is possible to build a layout in OO gauge (1:76 scale such as in a Hornby train set).  Please see the folder called 'Idea using OO gauge' for an idea of a layout in this scale.
